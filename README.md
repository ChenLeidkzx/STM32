## 项目调整记录

### 2026-08-29：移除 GitHub 自动同步功能

为了保持项目的连续性和简洁性，本次删除了 GitHub 自动同步相关的实现与说明。

原因是：

- 该功能本质上是为“自动提交、自动推送”而设计的辅助脚本；在项目路线中，它并不是核心功能。
- 自动同步会增加额外的 Git 操作、远程依赖和维护成本，容易造成仓库状态复杂化。
- 当前项目更注重硬件与云端协同逻辑本身，因此删去这类自动化脚本，有利于减少噪音、降低误操作风险。
- 这类功能依赖 Git、远程仓库配置和网络状态，若环境不稳定，会影响开发节奏。

本次调整包括：

- 删除 README 中关于 `sync.py` 自动提交和自动推送的说明。
- 停止依赖自动 GitHub 同步的开发方式，转回手动控制提交与推送。
- 明确保留项目本体功能，避免无关自动化脚本污染主线开发。

后续如果需要恢复该功能，建议再单独设计一个独立的工具脚本，并在 README 中说明其用途、适用场景和使用限制。
