# 智能刷题助手 · 软件部分

这是项目的**软件核心**——目前先完成了"云端 + 复习提醒算法"部分，纯 Python 编写，**电脑上就能运行和演示**，不需要硬件。

## 文件说明

| 文件 | 作用 |
|------|------|
| `review_algorithm.py` | **复习提醒算法**：根据遗忘曲线安排复习时间（第1/3/7/15/30天） |
| `question_model.py` | **错题数据**：定义错题结构，存到 `wrong_questions.json` |
| `cloud_demo.py` | **云端演示主程序**：添加错题 → 判断该复习哪些 → 生成清单 |
| `wrong_questions.json` | 错题数据文件（运行时自动生成） |

## 怎么运行

```bash
# 在 software 目录下
python3 review_algorithm.py   # 测试复习算法
python3 question_model.py     # 测试错题存储
python3 cloud_demo.py         # 运行云端演示
```
