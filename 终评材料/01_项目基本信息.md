### 课程真实经历（智伴鱼优·RISC-V AI 生态鱼缸，16学时12次课）

**课程全称**："智伴鱼优"——基于 RISC-V 的 AI 智能生态鱼缸。核心是用国产开源 RISC-V 开发板（赛昉 VisionFive 2 / JH7110），从零搭建一个能智能监测、远程控制、情感交互的生态鱼缸。走"开题→硬件→软件→AI→综合调试→路演"完整流程。

**硬件部分（真实做过）**：
1. 烧录/登录系统：balenaEtcher 烧录 Debian 到 TF 卡；串口(115200)/WiFi/SSH 三种方式登录；学会 MobaXterm 和 Linux 基础命令（ls/cd/mkdir/cp/mv）
2. 点亮 LED：GPIO 概念，VisionFive.gpio 库，面包板接 LED，Python 控制常亮/闪烁
3. 温湿度传感器 SHT30：I2C 协议（SDA+SCL 两线、半双工、独立地址），i2cdetect 确认 0x44 地址，每秒读温度(±0.3℃)湿度(±3%RH)
4. 继电器与马达：继电器原理（小电压 GPIO 控大电压负载），控制抽水/加水马达各5秒，实现自动换水
5. 综合硬件搭建：多功能控制板（接线端子+八路继电器+供电模块），传感器接 C7-C10、LED/马达接 A1-A10

**软件/AI 部分（真实做过）**：
1. Web 服务器：四层架构（Linux→系统软件→Python Web 后端→Web/AI 前端），Flask + JavaScript + HTML5 做鱼缸参数网页
2. AI 编程（VibeCoding）：用 Trae/Cursor/Qoder 自然语言写"鱼缸控制网页"（温度/PH 显示、视频监控、远程喂食加温、AI 互动），反馈让 AI 修 bug
3. AI 应用与智能体：调用 DeepSeek 大模型 API（Python + OpenAI SDK）；Dify/Coze 零代码搭 AI 应用；MCP 协议（"AI 世界的 USB"）——部署 MCP 服务器让智能体通过 Flask API 控鱼缸；用"小天/小智"智能体语音控制（点灯、读温度、换水）
4. 自己用 Python 迭代设计了一套自动化鱼缸管理程序，配合硬件模块检测鱼缸状态

**知识层面**：
- 跨学科：化学（氨氮/溶解氧/PH）、生物（生态系统/硝化系统）、信息科技（编程/Linux/智能体）、技术工程（开源软硬件/物联网）、人文（养老关怀/情绪价值）

## 6. 技术方案概要

- **开发工具**：MicroPython / Arduino 框架（降低硬件开发门槛）
