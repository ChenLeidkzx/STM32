**——让刷题不再做无用功**

## 一、项目由来（真实问题驱动）

刷题是高中生的日常，但我们发现：**刷了很多题，效果却很差**——
错题不整理、整理完也不复习，大量时间变成了"无用功"。
经过对身边同学的问卷调研，我们确认了这确实是普遍痛点。
于是想做一个能**帮我们把刷题变高效**的智能装置。

## 二、技术方案及应用价值

- **硬件**：STM32 单片机 + 实体按键 + 摄像头
- **云端**：数据上传 + 错题统计 + 主动复习提醒
- **价值**：独立硬件不碰手机（不分心）、成本低可推广、能真正提升错题复习效率

## 三、核心功能及创新点

| 功能 | 说明 |
|------|------|
| 一键标记 | 刷题时按一下实体按键，快速标记错题，不打断节奏 |
| 拍照记录 | 摄像头拍下题目，图片上传云端 |
| 云端统计 | 错题数量、薄弱点一目了然 |
| 主动提醒 | 按间隔复习规律，到期主动提醒回看错题 |

**创新点**：① 独立硬件、不依赖手机；② 不只是"存错题"，而是"主动提醒复习"；③ 软硬结合、成本低、可自行改造。

## 四、未来展望

- 接入 AI 识别，自动判断题目类型、推荐相似题；
- 支持按知识点生成个人学习报告；
- 整理方案参加科技赛事，让更多同学用上。
