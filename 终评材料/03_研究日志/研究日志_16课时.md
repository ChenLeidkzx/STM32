# 研究日志（16课时）

**课程**：智伴鱼优——基于 RISC-V 的 AI 智能生态鱼缸课程
**记录人**：陈磊
**学校**：江苏省天一中学
**说明**：本日志为课程 16 课时的完整学习记录，供终评综合评分使用。

---

## 第1课时 ｜ 课程开题：认识RISC-V与工程方法

**日期**：8.10
**学习内容**：课程整体介绍、认识 RISC-V 开源架构、学习工程项目方法
**实践记录**：
这节课老师介绍了"智伴鱼优"项目——用国产开源 RISC-V 开发板（赛昉 VisionFive 2 / JH7110）做一个能智能监测、远程控制、情感交互的生态鱼缸。我第一次听说 RISC-V，了解到它是和 x86、ARM 并列的三大主流指令集之一，而且是开源、自主可控的，对我们国家的芯片战略很重要。这节课还学习了工程项目的基本流程：开题报告、研究日志、查新报告、中期汇报、总结路演与答辩。
**遇到的问题/思考**：对 RISC-V 和 ARM 的区别还比较模糊。
**收获**：明白了"为什么要学这个课"，建立了工程方法意识。

## 第2课时 ｜ 确定课题与开题报告

**日期**：8.11
**学习内容**：确定课程研究课题、撰写开题报告
**实践记录**：
这节课要确定课程的研究课题，并按工程规范撰写开题报告。我围绕"生态鱼缸"主题，确定了研究方向和要解决的问题，学会了开题报告的结构和写法：选题意义、研究内容、研究方法、进度安排等。
**遇到的问题/思考**：研究范围一开始定得太大，老师提醒后缩小了范围。
**收获**：掌握了开题报告的规范写法，明确了课程课题。

## 第3课时 ｜ 硬件入门（一）：烧录系统与三种登录方式

**日期**：8.13
**学习内容**：系统烧录、终端登录、Linux 基础命令
**实践记录**：
这节课动手了！下载 Linux（Debian）系统镜像，用 balenaEtcher 烧录到 TF 卡，然后通过串口（波特率 115200）、WiFi、SSH 三种方式登录开发板。学会了用 MobaXterm 终端工具，掌握了 ls/cd/mkdir/cp/mv 这些 Linux 基础命令。虽然只是"让板子跑起来"，但第一次真正"控制"一块硬件，感觉很奇妙。
**遇到的问题/思考**：串口驱动装了好几次才成功；波特率设错会乱码。
**收获**：掌握烧录和远程登录，对硬件开发有了实感。

## 第4课时 ｜ 硬件入门（二）：GPIO点亮LED

**日期**：8.15
**学习内容**：GPIO 概念、VisionFive.gpio 库、面包板接线
**实践记录**：
这节课学 GPIO（通用输入/输出口）。安装 VisionFive.gpio 库，在面包板上按电路图接好 LED，用 Python 写程序让灯常亮、再按设定秒数闪烁。这是第一次用"程序控制硬件"，理解了高低电平、上拉下拉这些概念。我还试着把闪烁间隔改快改慢，观察灯的变化规律。
**遇到的问题/思考**：一开始正负极接反了，灯不亮，检查电路图才发现。
**收获**：打通了"Python→GPIO→硬件"这条链路，理解了 GPIO 的输出控制原理。

## 第5课时 ｜ I2C通信与SHT30温湿度传感器

**日期**：8.17
**学习内容**：I2C 通信协议、SHT30 传感器、i2cdetect
**实践记录**：
这节课学 I2C 通信协议——只靠 SDA 数据线 + SCL 时钟线两条线，半双工通信，每个设备有独立地址。连接 SHT30 温湿度传感器，用 i2cdetect 命令确认它在 0x44 地址挂载成功，然后写 Python 程序每秒读取并打印温度（精度 ±0.3℃）和湿度（±3%RH）。
**遇到的问题/思考**：刚开始读不到数据，排查发现是地址搞错了、线序接反。
**收获**：理解了传感器数据是怎么"读"出来的，学会了 I2C 排障方法。

## 第6课时 ｜ 继电器与马达：自动换水实验

**日期**：8.18
**学习内容**：继电器原理、控制马达
**实践记录**：
学继电器原理——用小电压的 GPIO 信号去控制大电压负载的"电动开关"。用 Python 程序控制抽水马达（5秒）和加水马达（5秒），完成了鱼缸自动换水（先抽水、再加水）的实验。
**遇到的问题/思考**：继电器模块接线端子比较多，一开始对不上哪个接哪个。
**收获**：理解了"弱电控强电"的思想，掌握了用程序控制外部设备执行动作的方法。

## 第7课时 ｜ 综合硬件搭建

**日期**：8.20
**学习内容**：多功能控制板、整机接线
**实践记录**：
这节课认识"多功能控制板"（接线端子 + 八路继电器 + 供电模块），把传感器接到 C7-C10 端子、LED 和马达接到 A1-A10 端子，完成整机连线。硬件部分从零散的模块变成了一个完整的系统。
**遇到的问题/思考**：线比较多，容易乱，我用标签把线分好类。
**收获**：掌握了整机布线的方法，体会到一个工程作品是"系统"而不是"零件"。

## 第8课时 ｜ 软件架构与Flask Web服务器

**日期**：8.21
**学习内容**：四层软件架构、Flask、网页开发
**实践记录**：
进入软件部分。学软件架构：Linux 层 → 系统软件层 → Python Web 后端 → Web/AI 前端四层。安装 Flask，用 PythonWeb + JavaScript + HTML5 写了一个网页，能在浏览器里显示鱼缸的环境参数（温度、湿度）。
**遇到的问题/思考**：前端 JS 和后端 Python 的数据交互一开始搞不清楚。
**收获**：打通了"硬件数据→网页展示"的整条链路，理解了 Web 后端的基本原理。

## 第9课时 ｜ AI编程（VibeCoding）：用自然语言写网页

**日期**：8.22
**学习内容**：Trae/Cursor/Qoder 等 AI 工具、提示词编程
**实践记录**：
这节课学 AI 编程（VibeCoding 氛围编程）。用 Trae/Cursor/Qoder 这些 AI 工具，通过自然语言提示词写"鱼缸控制网页"——包含温度、PH 显示、视频远程监控、远程喂食/加温、AI 互动控制。写完后还能反馈让 AI 优化 bug，比如"左侧菜单收不起来"，AI 就能定位修改。
**遇到的问题/思考**：提示词写得不清楚时，AI 生成的代码会有偏差，需要反复描述需求。
**收获**：第一次体会到"人机协作编程"，也学会了用 AI 工具快速开发原型。

## 第10课时 ｜ 调用大模型API：DeepSeek

**日期**：8.23
**学习内容**：大模型 API、Python + OpenAI SDK
**实践记录**：
学会调用 DeepSeek 大模型 API（用 Python + OpenAI SDK），让程序能"理解"自然语言并返回结果。我试了让大模型分析一段文字、生成摘要，理解了 API 的调用流程（请求→密钥→返回）。
**遇到的问题/思考**：API 密钥管理和调用参数要小心，否则会报错或超时。
**收获**：掌握了"程序接入大模型"的能力，理解了 AI 应用的基本调用方式。

## 第11课时 ｜ 零代码搭AI应用：Dify与Coze

**日期**：8.24
**学习内容**：Dify/Coze 平台、低代码/零代码搭 AI 应用
**实践记录**：
学用 Dify、Coze 平台，用零代码/低代码的方式搭 AI 应用和智能体。不用写太多代码，通过拖拽配置就能做出一个能对话、能执行任务的应用。
**遇到的问题/思考**：平台的编排逻辑（工作流）一开始不太熟。
**收获**：掌握了快速搭建 AI 应用的方法，理解了低代码平台的运作思路。

## 第12课时 ｜ MCP协议与智能体控制硬件

**日期**：8.25
**学习内容**：MCP 协议、部署 MCP 服务器、智能体调用
**实践记录**：
这节课很有收获。学 MCP 协议（模型上下文协议，被比喻成"AI 世界的 USB 协议"）——它让智能体能统一调用外部工具。我在开发板上部署了 MCP 服务器，让智能体通过它调用开发板的 Flask API 来控制鱼缸（开灯、读温度）。
**遇到的问题/思考**：MCP 的配置和调试花了挺长时间，但跑通后非常有成就感。
**收获**：理解了"智能体 + 工具调用"的架构，这是 AI 应用落地的关键。

## 第13课时 ｜ 语音智能体：小智控制鱼缸

**日期**：8.25
**学习内容**：开源智能体"小天/小智"、语音控制
**实践记录**：
用开源"小天/小智"智能体实现语音控制鱼缸——说一句话就能语音点灯、读温度、换水。这是整个课程里最"科幻"的一节课，人机交互变得非常自然。
**遇到的问题/思考**：语音识别的准确率受环境噪音影响，需要安静环境。
**收获**：体验了完整的"语音→智能体→硬件"闭环，理解了人机交互设计的重要性。

## 第14课时 ｜ 自主迭代：我的自动化鱼缸管理程序

**日期**：8.26
**学习内容**：综合运用、Python 迭代开发
**实践记录**：
学完课程主要内容后，我自己动手迭代设计了一套自动化鱼缸管理程序，配合硬件模块实时检测鱼缸状态（温度、湿度），并根据阈值自动执行控制逻辑。把之前学的 GPIO、传感器、继电器、Python 综合运用起来，程序从 v1 迭代到 v2、v3，逐步完善。
**遇到的问题/思考**：自动控制逻辑里阈值怎么定最合理，我查了资料参考生态鱼缸的水质标准。
**收获**：第一次独立完成一个"采集→判断→控制"的完整程序，动手能力和解决问题的能力提升明显。

## 小结

16 课时里，我从认识 RISC-V 开始，一步步学会了烧录系统、GPIO、I2C 传感器、继电器控制、Flask 网页、大模型 API、MCP 智能体、语音交互，最终独立完成了一套自动化鱼缸管理系统。这段课程经历让我掌握了嵌入式 + 云端的工程能力，也让我体会到：**学到的技术，最终要用来解决真实的问题**。
