# 基于STM32与云端协同的智能刷题助手

**——让刷题不再做无用功**

**小组成员**：陈磊（另需补充队友）　**学校**：江苏省天一中学　**指导教师**：冯丹沁

---

## 一、项目由来（真实问题驱动）

刷题是高中生的日常，但刷了很多题、效果却很差——错题不整理、整理完也不复习，大量时间变成了"无用功"。这个感受来自我的真实经历：中考冲刺阶段买了江苏大市13卷等习题册，很多是重复刷题、收效不大；尝试过"作业帮""必刷题理想树"的 AI 刷题，但太复杂。同学也常问"怎么刷题才有效"。于是想做一台**帮我们把刷题变高效**的智能装置。

## 二、技术方案及应用价值

- **硬件**：STM32F103C8T6 主控（按键逻辑）+ ESP32-CAM（摄像头+WiFi）
- **云端**：自建 Flask 云端服务（PythonAnywhere 公网部署，数据统计 + 可视化 + 主动复习提醒）
- **价值**：独立硬件不碰手机（不分心）、成本低可推广、能真正提升错题复习效率

## 三、核心功能及创新点

| 功能 | 说明 |
|------|------|
| 一键标记 | 刷题时按一下实体按键，快速标记错题，不打断节奏 |
| 拍照记录 | ESP32-CAM 拍下题目，图片上传云端 |
| 云端统计 | 错题数量、薄弱点一目了然 |
| 主动提醒 | 按间隔复习规律，到期主动提醒回看错题 |

**创新点**：① 独立硬件、不依赖手机；② 不只是"存错题"，而是"主动提醒复习"；③ 软硬结合、成本低、可自行改造。

## 四、未来展望

- 接入大模型 AI，生成个性化复习建议；
- 支持按知识点生成个人学习报告；
- 整理方案参加科技赛事，让更多同学用上。
