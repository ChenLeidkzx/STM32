## 一、项目概况

本项目针对同学们"刷题很多、效果很差"的现实问题，设计并制作了一台基于 STM32 单片机的智能刷题助手。设备通过实体按键实现"一键标记错题"，通过摄像头拍摄题目，数据上传到云端进行统计，并根据间隔复习规律主动生成复习提醒，帮助学生减少无效刷题、提高错题复习效率。项目采用"STM32 硬件 + 云端协同"的技术路线，从真实问题出发，完成了需求调研、方案设计、云端软件开发与部署等环节，硬件部分按计划推进中。

## 二、主要成果

### 1. 软件与云端成果（已实现）

采用 STM32F103C8T6 主控 + ESP32-CAM（摄像头+WiFi）+ 自建 Flask 云端服务的技术方案，目前已完成：

- **复习提醒算法**：按间隔重复规律（第1/3/7/15/30天）安排复习，用 Python 实现并通过单元测试；
- **云端服务**：用 Python Flask 自建云端程序（含错题数据管理、复习提醒判断），部署到 PythonAnywhere 免费公网平台，已上线可访问，支持网页展示和数据上传接口；
- **一键标记逻辑**：设计实体按键标记错题的数据上传方案（硬件到位后接入）。

## 三、研究过程回顾

（以下为过程简述，可结合研究日志展开）

1. **发现问题**：通过观察和调研，确认"刷题无效"是同学们普遍存在的痛点；
2. **理论学习**：查阅"刻意练习""间隔复习""遗忘曲线"等资料，为功能设计找依据；
3. **方案设计**：确定 STM32 + 按键 + 摄像头 + 自建云端的整体技术路线；
4. **云端开发**：编写复习提醒算法和错题管理程序，用 Flask 搭建云端服务，部署到免费公网平台并验证上传、展示、提醒全链路；
5. **用户调研**：设计问卷了解同学对 AI 辅助学习工具的需求；
6. **总结整理**：完成过程性资料，准备终评。

## 四、遇到的问题与解决

| 遇到的问题 | 解决办法 |
|-----------|---------|
| 复习提醒的"何时该复习"逻辑不易想清 | 参考遗忘曲线，用"间隔重复"简化实现（1/3/7/15/30天） |
| 云端服务本地能跑、部署到公网却报错 | 排查发现是本地开发用的 debug 模式与部署环境冲突，改为正式配置 |
| 本地端口被系统服务占用 | 更换端口解决 |
| 数据怎么上传到公网云端 | 设计 HTTP POST 接口，用 curl 验证上传、刷新页面实时显示 |
| 硬件尚未到位，演示如何准备 | 先用模拟数据打通"上传→云端→展示"全链路，硬件到位后替换为真实数据 |

## 五、收获与反思

### 收获

1. **知识与技能**：学会了 Python 网页开发（Flask）、云端部署、复习算法设计，理解了"软硬结合"的项目怎么做；
2. **研究方法**：完整走了一遍"发现问题 → 调研 → 设计 → 实现 → 测试 → 改进"的研究流程，理解了研究性学习是怎么回事；
3. **解决问题的能力**：遇到部署报错、端口占用等问题时学会主动排查、查资料解决；
4. **表达与展示**：学会了把复杂的东西讲清楚，为路演答辩积累了经验。

### 反思

1. 项目还有不少可以改进的地方：比如复习提醒算法可以更精细，云端功能可以更丰富；
2. 前期对硬件部分的时间估计不足，硬件采购和搭建比预想慢，以后做项目要留更多缓冲时间；
3. 目前队伍只有我一个人，如果组队完成，硬件、软件、文档可以分工推进，效率会更高；
4. 如果继续做下去，可以加入更多 AI 能力（比如自动识别题目、智能推荐相似题）。
