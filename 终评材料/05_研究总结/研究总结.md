## 一、项目概况

本项目针对同学们"刷题很多、效果很差"的现实问题，设计并制作了一台基于 STM32 单片机的智能刷题助手。设备通过实体按键实现"一键标记错题"，通过摄像头拍摄题目，数据上传到云端进行统计，并根据间隔复习规律主动生成复习提醒，帮助学生减少无效刷题、提高错题复习效率。项目采用"STM32 硬件 + 云端协同"的技术路线，从真实问题出发，完成了从需求调研、方案设计、硬件搭建、软件开发到真实试用的一整套研究过程。

## 二、主要成果

### 1. 实物成果

完成了一台可运行的智能刷题助手样机，采用 STM32F103C8T6 主控 + ESP32-CAM（摄像头+WiFi）+ 自建 Flask 云端服务的技术方案，具备以下功能：

- **一键标记**：刷题时遇到难题/错题，按一下实体按键即可标记，不打断学习节奏；
- **拍照记录**：ESP32-CAM 摄像头可拍摄题目图片；
- **云端协同**：标记信息和图片上传云端（Flask + PythonAnywhere 公网服务），实现错题数据统计与可视化展示；
- **主动提醒**：云端依据间隔复习规律生成复习提醒，到期主动提示回看错题。

## 三、研究过程回顾

（以下为过程简述，可结合研究日志展开）

1. **发现问题**：通过观察和调研，确认"刷题无效"是同学们普遍存在的痛点；
2. **理论学习**：查阅"刻意练习""间隔复习""遗忘曲线"等资料，为功能设计找依据；
3. **方案设计**：确定 STM32 + 按键 + 摄像头 + 云端的整体技术路线；
4. **动手实现**：分模块搭建硬件、编写程序、逐步联调，克服了按键消抖、摄像头配置、图片传输、供电不稳等一系列问题；
5. **试用改进**：在真实场景试用，根据同学反馈优化；
6. **总结整理**：完成过程性资料，准备终评。

## 四、遇到的问题与解决

| 遇到的问题 | 解决办法 |
|-----------|---------|
| 按键抖动导致误触发 | 学习并采用延时消抖方法 |
| 摄像头模块配置复杂 | 查阅数据手册，按教程逐步调试 |
| 图片过大、云端上传慢 | 对图片做压缩处理 |
| 多模块整合时供电不稳 | 增加稳压，排查供电线路 |
| 按键连按重复标记 | 程序里增加"冷却时间" |

## 五、收获与反思

### 收获

1. **知识与技能**：学会了 STM32/嵌入式开发、传感器模块使用、Flask 网页、大模型 API、MCP 智能体、基础的物联网云端接入，动手能力提升明显；
2. **研究方法**：完整走了一遍"发现问题 → 调研 → 设计 → 实现 → 测试 → 改进"的研究流程，理解了研究性学习是怎么回事；
3. **能力迁移**：学会了把学到的技术（GPIO/I2C/云端/AI）运用到新的应用场景，这是比具体技术更宝贵的能力；
4. **表达与展示**：学会了把复杂的东西讲清楚，为路演答辩积累了经验。

### 反思

1. 项目还有不少可以改进的地方：比如复习提醒算法可以更精细，外观可以更好看，云端功能可以更丰富；
2. 前期对时间估计不足，有些模块调试比预想慢，以后做项目要留更多缓冲时间；
3. 目前队伍只有我一个人，如果组队完成，硬件、软件、文档可以分工推进，效率会更高；
4. 如果继续做下去，可以加入更多 AI 能力（比如自动识别题目、智能推荐相似题）。

## 六、展望

希望这个项目不只是"一次作业"，而能真正成为同学们学习中的有用工具。后续计划：
