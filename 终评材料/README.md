# 终评材料

> 基于 STM32 与云端协同的阳光伴学助手

这里分为两套材料：

## 01_评委材料

提交或展示给评委的正式材料，建议优先阅读：

1. 项目基本信息
2. 开题报告
3. 查新报告
4. 研究总结
5. A4 展示页文案

## 02_个人备战

答辩前使用的准备资料和过程留档：

- `行动清单.md`：提交前待办事项
- `备战手册.md`：整体准备安排
- `答辩与展示/`：答辩题库、PPT 大纲、路演脚本
- `用户调研/`：问卷与报告模板
- `硬件采购/`：采购清单与搜索参考
- `研究记录/`：不随正式材料提交的课时研究记录

正式打包提交时，只需使用 `01_评委材料/`。
